# 真实验证结果（终审修订版，2026-11-22）

## 本次修订说明（重要）

此前 `scripts/validate_real_generation.py` 用的是**脚本自带的批量场景 prompt**，
并非生产代码的 prompt：生产实际运行的是 `app/domain/courseware.py` 的
`SCENE_SYSTEM` + 逐场景 `build_courseware`，两者从未用真实 API 一起跑过。
"prompt 已被真实验证"的说法不成立。

**现已修正**：脚本重写为直接调用**生产入口**
`build_courseware(SAMPLE_LECTURE, DeepSeekClient(http_client=httpx.Client(timeout=120)))`，
不再自建并行 prompt 流水线。真实跑一遍就是跑上线代码。

- 运行命令：`python -m scripts.validate_real_generation`（仓库根目录，key 从 gitignored `.env`
  经 `app.config.settings` 读取；脚本只把 key 交给 client，**从不打印 key**）。
- 真实后端：`https://api.deepseek.com`，模型 `deepseek-chat`。
- 输入：讲义样例「一元二次方程的配方法」（理解→大纲→逐场景→测验，含单场景降级路径）。
- 输出：完整 Courseware 以 UTF-8 JSON 打印，并写入工作副本根目录的
  `validation_output.json` 供人工检查；**该文件含生成内容、不含 key，仅本地检查用，
  未提交、不进版本库**。

## 观察到的产出与内容判断（真实 DeepSeek 返回）

产出 `version="1.0"`，`title="一元二次方程的配方法"`，`subject="数学"`，`grade="九年级"`；
`aigc = {label:"AI辅助生成", provider:"deepseek", model:"deepseek-chat"}`。
共 **12 个场景**（受 `max_scenes=12` 上限约束）与 **3 道单选题**，无 `degraded` 占位场景。

按原有 6 条标准逐项判断（全部通过）：

1. **Schema 合法**：version/title/subject/grade/scenes/quiz/aigc 齐全；场景均含
   type/title/bullets/narration/visual_hint（其中 1 个场景 visual_hint 为空，属可选字段）。
2. **理解正确**：准确提取主题「一元二次方程的配方法」、学科「数学」、年级「九年级」与核心知识点。
3. **教学结构完整**：引入 → 配方法概念 → 配方原理 → 关键步骤总览 → 步骤细化（系数化1/移项、配方/开平方）
   → 例题1 → 例题2 → 三个易错点 → 小结，覆盖设计要求的「引入→概念→步骤→例题→易错点」。
4. **场景内容充实**：每个场景都有非空标题、要点与讲稿，旁白为可直接上课的教师口吻；
   无空白/降级场景（`{}` 与空内容已在生产路径中被当作失败并重试/降级，见 courseware.py）。
5. **测验达标**：3 道单选题，每题 4 个选项、0-based answer 与解析；题目考察真实知识点。
6. **学科正确性与合规**：例题演算正确（x²+6x+5=0 → x₁=-1, x₂=-5；2x²-4x-6=0 → x₁=3, x₂=-1；
   开平方取 ±、配方两边同加等易错点均讲解正确）；带 AIGC 标注，provider/model 取自真实客户端。

结论：**上线的 `build_courseware` 编排本身**在真实 DeepSeek 下产出可用、结构完整、学科正确、
带合规标注的课件；此前"脚本 prompt 与生产不一致"的缺口已关闭。
